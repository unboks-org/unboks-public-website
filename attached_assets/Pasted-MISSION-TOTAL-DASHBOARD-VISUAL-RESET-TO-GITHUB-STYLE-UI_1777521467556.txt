PAGE-SPECIFIC REQUIREMENTS

INBOX PAGE

The Inbox must look like a GitHub Issues list.

Required:
- top filter/search row
- channel filter chips/dropdowns if already present
- bordered list container
- rows with checkbox, source, customer, preview, status, time
- row click opens detail pane or detail view
- no overlapping text
- no duplicated “WhatsApp / WhatsApp” confusion

Column meaning:
- Source = WhatsApp, Instagram, Facebook, Email, etc.
- Customer = person/account name
- Preview = message summary
- Status = unread/escalated/open/closed if needed
- Time = last message time

Important actions:
- Mark as Read visible
- Archive visible
- Reply visible
- Not hover-only

ESCALATIONS PAGE

Use same GitHub-style list pattern.

Required row data:
- source
- customer
- escalation type: Soft or Hard
- short reason/summary
- time
- status

Soft escalation:
- human replies to AI/operator, AI continues customer response

Hard escalation:
- human directly takes over customer conversation

The row must explain why it needs attention.

BOOKINGS / ORDERS PAGE

No useless stats wall.

Use GitHub-style practical list.

Required:
- small filter/summary bar at top
- if a metric/filter is clicked, main list changes to exactly those items
- clicking “Booked Today: 3” must show exactly 3 booking rows, not a dashboard overview
- booking rows show:
  - customer
  - trip/service/product
  - date/time
  - party size / guests
  - status
- clicking a row opens details:
  - customer name
  - contact
  - trip/service
  - date/time
  - number of people
  - notes
  - original message if available

Do not show random analytics unless useful and clickable.

CHANNELS PAGE

GitHub settings/list style.

Each channel row:
- platform
- connected account
- status
- last sync
- action button

No large colorful tiles.

SETTINGS PAGE

GitHub settings page style.

Use simple bordered sections.

Settings may include:
- Account/client settings
- Source of Truth / Knowledge files
- Business rules
- Escalation rules
- Team/users if already present
- Advanced settings collapsed or clearly separated

Source of Truth must live under Settings, not main nav.

Advanced AI/prompt controls must not be visible in normal daily dashboard view.
