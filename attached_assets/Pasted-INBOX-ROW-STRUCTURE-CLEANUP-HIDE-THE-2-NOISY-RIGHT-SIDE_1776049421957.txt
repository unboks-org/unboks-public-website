INBOX ROW STRUCTURE CLEANUP — HIDE THE 2 NOISY RIGHT-SIDE COLUMNS AND FIX THE FIRST 2 COLUMNS SO THEY SHOW USEFUL HUMAN INFO

PROBLEM
The current inbox row structure is wrong in 2 ways:

1. The 2 extra right-side columns with the channel icon + number/count are noisy and not useful in list view.
   Hide/remove those 2 columns from the inbox rows.

2. The first 2 columns are redundant and ugly.
   Right now I get things like:
   - WhatsApp | WhatsApp
   - Email | Email
This is wrong.
The row should show useful human-readable information, not repeated channel labels.

GOAL
Clean up the row structure so it becomes more practical and easier to scan.

REQUIRED CHANGES

PART 1 — HIDE / REMOVE THESE 2 RIGHT-SIDE COLUMNS
Hide/remove the 2 noisy columns on the right that currently show:
- channel icon
- numeric count/value next to it

These do not add enough value in the list view and create clutter.

Remove them from the row list UI.
Do not remove the underlying data if it is still needed internally.
Just stop rendering them in the inbox row.

PART 2 — FIX THE FIRST 2 COLUMNS
Replace the current duplicated channel/channel setup with a cleaner human-readable row structure.

NEW REQUIRED ROW STRUCTURE
The left/main part of each row should prioritize:

1. Sender / customer identity
2. Channel badge
3. Message preview/snippet

That means:
- Column 1 should show the sender/customer name if available
- Column 2 should NOT repeat the same channel as plain text again
- Instead, use a small channel badge/tag next to the sender identity or as part of the identity block
- Then show the message preview
